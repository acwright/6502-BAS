6502-BAS
========

BASIC program listings for the [A.C. Wright 6502 project](https://github.com/acwright/6502).

## Supported BASIC Versions

This repository contains program listings for two BASIC interpreters:

### IntegerBASIC
Located in the `IntegerBASIC/` folder. This is the version built into the system ROM and is always available at power-on.

### EhBASIC
Located in the `EhBASIC/` folder. This enhanced BASIC is distributed as a cartridge ROM and provides additional features beyond the built-in Integer BASIC.

## Usage

These are BASIC program listings meant to be typed directly into the BASIC interpreter. There are no build instructions or compilation steps - simply type the program listings into your system and run them.
